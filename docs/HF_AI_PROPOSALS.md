# Propuestas de mejoras con Hugging Face para Farmacia POS (demo)

Demo pública de sistema POS para farmacias (caja, gestión, químico farmacéutico).

## Propuestas

1. **Asistente de búsqueda de productos y stock** en lenguaje natural.
2. **Alertas de vencimientos o stock bajo** (análisis de patrones).
3. **OCR de recetas o etiquetas** (con cuidado de datos de salud).
4. **Sugerencias de productos relacionados**.

Solo datos de ejemplo. Ver `docs/CLAUDE_AI_TASKS.md`.
